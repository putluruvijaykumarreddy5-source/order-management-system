# Order Management System

## Project Description

Order Management System is a Java web application developed to manage customers, products, users, and orders.

The project is built using Java, Jakarta Servlets, JSP, JSTL, Maven, and PostgreSQL. It demonstrates CRUD operations, database connectivity, order management, and web application development.

## Technologies Used

- Java 17
- Jakarta Servlets 6.0
- JSP
- JSTL
- Maven
- PostgreSQL
- Apache Tomcat 10.1
- HTML/CSS
- Git & GitHub

## Main Features

- User management
- Customer management
- Product management
- Order management
- Order item management
- PostgreSQL database integration
- CRUD operations
- Servlet-based web application

## Database

The application uses PostgreSQL as the database.

Main tables:

- `app_users`
- `customers`
- `products`
- `orders`
- `order_items`
